A.2 Recovering Homographies

A homography maps a point (x, y) to (x′, y′) with p′ = Hp, where H is 3 × 3. I fix the bottom-right entry to 1, which leaves 8 unknowns. Writing it out, each correspondence gives two linear equations:

xh1 + yh2 + h3 − x′xh7 − x′yh8 = x′
xh4 + yh5 + h6 − y′xh7 − y′yh8 = y′

Four points would be enough to solve exactly, but a couple of pixels of clicking error throws that off a lot. So I clicked more points and solved the overdetermined system Ah = b with least squares. I picked sharp corners and small points (like the light of a lightbulb) spread across the whole overlap.

A.3 Warping the Images

I used inverse warping, which maps each output pixel back to its corresponding location in the source image using H⁻¹, preventing gaps in the output. To determine the output size, I transformed the four corners of the source image using H and used their bounding box. Pixels that mapped outside the source image were given an alpha value of 0 to make them transparent. I also treated (0, 0) as the center of the top-left pixel.

For interpolation, nearest neighbor rounds each source coordinate to the closest pixel, while bilinear interpolation calculates a weighted average of the four surrounding pixels based on their distances from the mapped location.

Rectification

To test the warp, I clicked the four corners of an object I know is rectangular and mapped them to a rectangle with the object's real aspect ratio. The rest of the image gets warped along with it.

Nearest neighbor was faster (0.11 s vs. 0.26 s on average), since it reads one pixel instead of four. But zoomed in, its edges are jagged and stair-stepped, which is easiest to see on the letters in "FREE BOOKS!" and "BAIR PAIR." Bilinear is a little softer but much smoother, so I used it for the mosaics.

A.4 Blending the Images into a Mosaic

I use the middle image as the reference and warp the others into its coordinate system, chaining homographies through neighboring images when needed. I transform each image's corners to determine the final canvas size, then warp all the images onto it.

To avoid hard seams and ghosting, I use a 2-level Laplacian pyramid. Each image gets an alpha mask based on its distance from the edges, which I warp along with the image. I split each image into low frequencies (Gaussian blur with σ = 5) and high frequencies (the original minus the blur). I blend the low frequencies with an alpha-weighted average to smooth exposure differences, then take the high frequencies from the image with the highest alpha at each pixel to keep details sharp.
